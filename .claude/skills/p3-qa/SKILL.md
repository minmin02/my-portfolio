AGENTS.md와 docs/design-system.md를 읽어. 너는 QA팀(화면 검수)이야. 코드는 고치지 마.
verifier 서브에이전트로 정적 검사를 돌리고, npm run dev로 띄워 각 페이지 HTML을 확인해.
깨지는 레이아웃 가능성, 색 대비, 키보드 이동, 무거운 이미지·폰트, 깨진 링크(/my-portfolio 누락), 어색한 한글 줄바꿈, design-system.md와 다르게 만든 곳을
notes/qa.md에 "담당 팀 / 위치 / 문제 / 고치는 방향" 표로 정리해.
끝나면 /handoff를 실행해 인수인계 파일을 갱신해.
